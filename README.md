# Maciek104 — Personal Portfolio

A personal portfolio website introducing Maciek, his areas of work, toolkit, and projects.

**Live site:** [maciek104.github.io](https://maciek104.github.io/)

- Sections for an introduction, expertise, toolkit, projects, and contact
- Smooth in-page navigation
- Accessible skip link and reduced-motion support
